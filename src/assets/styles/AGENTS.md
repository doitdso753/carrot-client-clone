# styles/
## 디렉토리 개요
css 파일 모음

## 코드 컨벤션
- Tailwind Utility Class를 기본으로 사용한다.
- 모바일, 태블릿, 데스크톱 반응형을 기본으로 구현한다.
- **Mobile First** 방식으로 개발한다.
- 레이아웃은 **Flex**를 기본으로 사용한다.
- 간격은 `margin`보다 `gap`을 우선한다.
- 2차원 레이아웃만 **Grid**를 사용한다.
- 고정 Width/Height 사용 지양
- !important 사용 지양
- 설정 값은 brand.css, tailwindcss 토큰을 우선 사용한다.
